# 상담 후 업무 정리 시연

실제 AI 에이전트 구축을 제외하고 사용 흐름을 먼저 체험하려는 요청에 따라 `/live/ai-demo`를 추가했다. 기존 업무 화면 상단의 `AI 업무 정리 시연` 링크로 접근한다. 예시만 사용하는 공개 화면으로 로그인이 필요하지 않다.

## 체험 흐름

1. 견적·연락 요청, 날짜 없는 요청, 기존 업무가 있는 요청 중 예시를 선택한다.
2. 고정된 예시 상담에 맞춰 준비한 요약·업무·날짜·근거를 표시한다.
3. 사용자가 요약과 업무 종류·내용·날짜를 수정하고, 불필요한 업무를 해제한다.
4. 확인란을 선택하고 승인하면 시연용 업무함에 반영한다. 기존 업무는 유지하고 선택한 새 업무만 추가한다.
5. 완료 표시·취소, 다른 예시 재시작을 체험한다.

## 범위

- 결과는 미리 작성한 시나리오 데이터다. 실제 AI 판단, 임의 텍스트 분석, 녹음 수집, STT, 외부 발송은 수행하지 않는다.
- 화면 전체에 시연임을 표시한다. 상담 요약과 업무는 React 상태에만 보관하며 API·고객 DB·브라우저 영구 저장소에 쓰지 않는다. 새로고침이나 화면 이탈 시 초기화된다.
- 기록 없는 날짜는 빈 값으로 제시한다. 사용자가 날짜를 비워 두고 승인하면 `기한 확인 필요`로 표시한다.
- 중복 제외 사례도 준비된 결과다. 실제 고객 DB를 조회해 중복을 추론하는 기능으로 간주하지 않는다.
- 실제 에이전트의 정확도나 시간 절감 효과를 검증한 것이 아니다. 사용자가 흐름을 이해하는지, 수정·승인 부담이 적절한지 확인하기 위한 화면이다.

## 검수

타입 검사와 웹 빌드 통과. 브라우저에서 업무 내용 수정·선택 해제 후 1건만 등록, 확인 전 승인 비활성, 날짜 미정 등록, 기존 업무 1건과 새 업무 1건의 합계 유지, 완료 표시, 재시작을 확인했다. 데스크톱 결과 화면 배치를 확인했다.
